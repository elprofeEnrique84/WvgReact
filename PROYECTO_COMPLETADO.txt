📋 ENDPOINTS API REQUERIDOS (24 total)

  AUTENTICACIÓN (4 endpoints)
    POST   /api/auth/login          Inicio de sesión
    POST   /api/auth/logout         Cerrar sesión
    POST   /api/auth/refresh        Refrescar token
    GET    /api/auth/me             Obtener usuario actual

  MANTENIMIENTOS (7 endpoints)
    GET    /api/mantenimientos      Listado con filtros
    GET    /api/mantenimientos/:id  Detalle
    POST   /api/mantenimientos      Crear
    PUT    /api/mantenimientos/:id  Actualizar
    DELETE /api/mantenimientos/:id  Eliminar
    PATCH  /api/mantenimientos/:id/status  Cambiar estado
    GET    /api/mantenimientos/:id/bitacora  Obtener bitácora
